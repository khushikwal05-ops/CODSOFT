## ✅ Tasks Completed: 3/4

### Task 1: Rule-Based Chatbot 🤖
**File:** `chatbot.py`  
**Objective:** Build a conversational chatbot using rule-based logic.

**Key Features:**
- Regex pattern matching for intent recognition
- Dynamic responses using `random.choice()` 
- Handles greetings, FAQs, jokes, and graceful exit
- Case-insensitive user input processing

**Tech Stack:** Python, Regex, Random Library

---

### Task 2: Tic-Tac-Toe AI 🎮
**File:** `tic-tac-toe.py`  
**Objective:** Create an unbeatable AI opponent for Tic-Tac-Toe.

**Key Features:**
- Implements **Minimax Algorithm** with Game Theory
- AI explores all possible moves to guarantee win/draw
- Player vs AI gameplay with clean console UI
- Optimal decision-making - AI never loses

**Tech Stack:** Python, Minimax Algorithm, Recursion

---

### Task 4: Movie Recommendation System 🎬
**File:** `recommendation_system.py`  
**Objective:** Build a content-based movie recommender.

**Key Features:**
- Uses **TF-IDF Vectorization** on movie genres + keywords
- **Cosine Similarity** to find similar movies
- Interactive CLI - enter any movie to get 3 recommendations
- Handles invalid inputs gracefully

**Tech Stack:** Python, Pandas, Scikit-learn, NumPy
